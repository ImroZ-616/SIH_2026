# Dataset

## Objective

Create a speaker-diverse dataset for custom keyword spotting.

## Classes

### Positive

Target keyword.

### Unknown

Normal speech that is not the target keyword.

### Negative / Hard Negatives

Words or phrases that sound similar to the target keyword.

### Silence / Background

Non-speech and environmental audio.

## Data Sources

- Custom recordings
- Public open-source speech datasets
- Background noise datasets

## Augmentation

- Noise injection
- Gain variation
- Time shifting
- Time stretching
- Pitch variation
- Reverberation
